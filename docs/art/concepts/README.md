# Invader Break concept images

These are generated art-direction proposals, not screenshots or evidence of implemented graphics/performance. The written game specification governs mechanics, proportions, and HUD values. Any illustrative wave counter or skeletal diagram is decorative.

- `invader-break-gameplay-target.png`: fixed-view 2.5D arena, two independent shield paddles, one white ball, hostile coral projectiles, and three shared shield icons.
- `invader-break-visual-development.png`: enemy, boss, paddle, material and effect studies using the gameplay concept as the style reference.

Created with the built-in image generation tool on 2026-09-16. Prompt records are in `../image-prompts.md`. Production meshes, materials, animations, UI, and effects must be created and validated separately.
